# Vision Content Engine

Infrastructure interne de création et de distribution organique pour **Vision**.

## Statut
Conception V1 — source de vérité avant implémentation.

## Objectif
Transformer des briefs et idées en contenus short-form de haute qualité, les produire, les faire valider, les publier sur TikTok / Instagram Reels / YouTube Shorts, puis mesurer les performances et alimenter les prochains tests.

## Principe directeur
Automatiser ce qui fait gagner du temps, sans automatiser ce qui détruit l'authenticité ou la qualité.

## Source de vérité
Les décisions validées vivent dans `docs/DECISIONS.md` et les ADR dans `docs/adr/`.
Le code futur doit suivre la spécification, pas l'inverse.
