# Fixture Catalog

Implementation must create a small synthetic fixture catalog covering:

- valid and invalid AI contract payloads;
- deterministic Campaign/Brief/Concept/Script/CreativePlan lineage;
- SDR portrait video;
- HDR/HLG sample where practical;
- rotated phone video;
- green-screen presenter clip;
- voice/music/silence audio;
- black/corrupt media;
- deterministic Vision-like capture fixture page;
- fake Instagram/YouTube provider responses;
- TikTok manual-handoff data;
- Umami/Vision attribution events.

No real customer data or production credential belongs in this catalog.
