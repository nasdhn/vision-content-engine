# Analytics & Learning Spec Artifacts

Status: specification artifacts only.

Core rules:
- raw provider evidence is immutable;
- normalized values use NULL for unavailable/unobserved;
- platform metric semantics are not assumed identical;
- content is compared at comparable measurement ages;
- business attribution is DIRECT / INFERRED / UNKNOWN;
- Vision product events arrive through a signed ingest boundary, never direct DB coupling;
- TikTok V1 analytics is manual rather than scraped;
- Analyst creates Insights/Recommendations but does not autonomously rewrite strategy.
