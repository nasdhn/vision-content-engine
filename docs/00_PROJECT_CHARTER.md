# 00 — Project Charter

## Nom de travail
Vision Content Engine

## Finalité
Construire une infrastructure interne permettant à Vision d'être présent de façon régulière et qualitative sur les réseaux sociaux short-form.

## Priorité business
Le projet sert d'abord Vision. Il n'est pas conçu comme un SaaS générique dans sa V1.

## Résultat attendu
À terme proche :
- environ 3 contenus originaux par jour ;
- distribution sur TikTok, Instagram Reels et YouTube Shorts ;
- présence humaine naturelle lorsque cela améliore le contenu ;
- production automatisée au maximum ;
- qualité de montage comparable à un bon monteur short-form ;
- validation humaine au début ;
- publication automatique après validation ;
- analytics + boucle d'apprentissage.

## North Star
Le système ne cherche pas uniquement les vues.
Il cherche à produire de l'attention qualifiée qui contribue à :
contenu → visite → inscription → activation → client.

## Non-objectifs V1
- devenir un SaaS multi-client ;
- supprimer toute intervention humaine ;
- produire des avatars IA génériques ;
- publier sans contrôle dès le jour 1 ;
- construire une architecture distribuée inutilement complexe.

## Critère de succès V1
Le système doit réellement permettre de produire, valider, publier et mesurer un flux régulier de contenus Vision sans dépendre d'un montage manuel complet pour chaque vidéo.
