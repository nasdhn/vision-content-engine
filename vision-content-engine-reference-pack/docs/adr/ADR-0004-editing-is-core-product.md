# ADR-0004 — Editing Intelligence is a core product domain

## Status
Accepted

## Decision
Le montage n'est pas une simple étape de rendering.

## Rationale
Une vidéo techniquement valide mais mal montée détruit la rétention et la perception de qualité.

## Consequence
Le projet possède des concepts propres :
- EditingPlan
- EditingProfile
- CreativeQA
- structured feedback
- montage versionné/testable.
