# 01 — Product Scope V1

## Pipeline V1

Brief hebdomadaire
→ Concepts
→ Validation humaine
→ Scripts + Creative Plans
→ Recording Pack si nécessaire
→ Assets / voix / clips / captures produit
→ Editing Plan
→ Automated Edit
→ Creative QA
→ Render
→ Review humaine
→ Scheduling
→ Publication
→ Analytics
→ Rapport hebdomadaire

## Plateformes V1
- TikTok
- Instagram Reels
- YouTube Shorts

## Formats humains
Pas de facecam classique comme exigence.
Format humain principal :
- incrustation fond vert ;
- environ moitié du visage ;
- geste / doigt pointant vers le contenu ;
- contenu principal visible derrière / à côté.

## Voix
- vraie voix naturelle par défaut ;
- enregistrement humain accepté comme étape normale ;
- voix IA non prioritaire.

## Familles de contenu V1
1. Product Demo
2. Manual → Vision
3. Problem → Solution
4. Human / Founder
5. variantes dérivées de patterns validés

## Validation humaine
Obligatoire au départ :
1. validation des concepts ;
2. validation des vidéos finales.

Le script reste éditable mais n'est pas une gate obligatoire indépendante.

## Publication
Phase initiale :
vidéo approuvée → scheduling → publication automatique.

Phase ultérieure :
publication autonome pour catégories suffisamment fiables.

## Hors scope V1
- recherche sociale autonome complète ;
- scraping massif de créateurs ;
- multi-user / multi-brand ;
- billing ;
- LinkedIn / X ;
- avatars IA ;
- attribution multi-touch avancée ;
- fine-tuning ;
- Kubernetes ;
- Temporal ;
- publication sans garde-fous.
