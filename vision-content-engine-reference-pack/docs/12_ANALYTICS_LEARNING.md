# 12 — Analytics & Learning

## Deux niveaux de données
### Raw
Réponses plateforme immuables.

### Normalized
Métriques comparables lorsque possible :
- views
- likes
- comments
- shares
- saves
- watch time
- avg watch duration
- completion / retention signals
- profile signals
- website signals

Inconnu = NULL.

## Expérimentation
Chaque contenu doit conserver :
- hypothesis
- topic
- angle
- hookType
- pattern
- template
- editingProfile
- CTA
- duration
- platform

## Rapport hebdomadaire
Doit distinguer :
- faits ;
- signaux faibles ;
- signaux intéressants ;
- données insuffisantes ;
- hypothèses ;
- tests suivants.

## Règle
Le système ne conclut pas qu'un pattern est « gagnant » sur quelques observations seulement.
